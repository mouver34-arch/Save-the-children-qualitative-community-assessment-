## Suggested LinkedIn project description

Public portfolio demonstration based on my experience supporting a Save the Children qualitative field assessment in Jigawa State in March 2025. The repository demonstrates how qualitative field information can be structured, coded and organized into themes using entirely synthetic data. It covers FGD/KII organization, Hausa-to-English transcription workflow, qualitative coding, stakeholder-perspective comparison and evidence-based reporting, while deliberately excluding participant information, real quotations, confidential findings and restricted organizational materials.
