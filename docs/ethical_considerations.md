# Ethical and confidentiality considerations

## Public repository boundary

This repository is designed for public professional demonstration. It must not contain source material from a restricted field assignment unless the owner has explicit permission to publish it.

### Never publish

- Names or direct identifiers
- Phone numbers
- NIN/BVN or other identity numbers
- Exact addresses
- Identifiable geolocation of vulnerable participants
- Child-identifying information
- Real participant quotations without explicit publication approval
- Confidential programme findings
- Internal reports, forms or questionnaires
- Passwords, API keys, access tokens or private URLs

## Synthetic replacement

When a real example would create confidentiality risk, this repository uses a fictional record instead. Synthetic records are labelled clearly so that portfolio reviewers do not mistake them for field findings.

## Safeguarding

The presence of children or other potentially vulnerable participants in the real-world context makes data minimization and safeguarding particularly important. Public portfolio material should demonstrate professional judgment without exposing people to identification or harm.

## Publication checklist

Before publishing any future fieldwork repository:

- Remove all real records.
- Search for phone-number-like strings and identity numbers.
- Search for names and addresses.
- Check file metadata where practical.
- Check Git history for accidentally committed secrets.
- Remove internal URLs and credentials.
- Confirm that any quotations are explicitly publishable.
- Confirm that organizational branding/documents are permitted for public use.
