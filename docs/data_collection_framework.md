# Data collection framework

The public demonstration uses a compact structure for FGD and KII records.

| Field | Purpose |
|---|---|
| record_id | Safe synthetic record identifier |
| method | FGD or KII |
| participant_group | Stakeholder/participant category |
| community | Community context |
| language | Source-language label |
| transcript_excerpt_en | Fictional English transcription excerpt |
| initial_code | Descriptive first-level code |
| theme | Broader analytical theme |
| evidence_type | Experience, challenge, response or recommendation |

## Fieldwork context supported by the user's professional experience

The March 2025 Save the Children assessment involved community engagement, FGDs, KIIs, Hausa-language interviewing and English transcription in Jigawa State.

The public dataset intentionally abstracts away from real interview guides, real respondent details and actual assessment findings.
